# @ic-reactor/react

> **ic-reactor 4 is in development on the `v4` branch.** This package is at a
> `4.0.0-alpha` version that is not published, and it exports nothing yet: the
> 3.x hooks were removed so that the 4 bindings can be built on
> `@ic-reactor/core` 4 (milestone 1,
> [#790](https://github.com/B3Pay/ic-reactor/issues/790)).

ic-reactor 4's React package is a small set of `'use client'` bindings: a
provider that owns one client per tree, `useClient` and `useAuth`. They arrive
with IR6 ([#780](https://github.com/B3Pay/ic-reactor/issues/780)). Until then
this README is a placeholder.

## 3.x

The released 3.x package, with its hook factories and auth hooks, is documented
at https://ic-reactor.b3pay.net/v3/packages/react. Its source and security fixes
live on the `main` branch.
