ic-reactor 4 is developed on the
[`v4` branch](https://github.com/B3Pay/ic-reactor/tree/v4). Its first
prerelease, `4.0.0-beta.1`, is published under npm's `beta` dist-tag; `latest`
stays 3.x until 4.0 GA, so install it as `@ic-reactor/core@beta`. Its guide
ships in the package, at `node_modules/@ic-reactor/core/llms.txt`. These pages
are rewritten for 4 in a later change.

The released 3.x packages are documented at [ic-reactor.b3pay.net/v3](https://ic-reactor.b3pay.net/v3/).

The API reference in the sidebar is generated from the `v4` branch as it
stands.
