ic-reactor 4 is in development on the
[`v4` branch](https://github.com/B3Pay/ic-reactor/tree/v4). Nothing from it is
released yet, and these pages describe no 4.x API. The documentation lands
with the guide in a later change.

The released 3.x packages are documented at [ic-reactor.b3pay.net/v3](https://ic-reactor.b3pay.net/v3/).

The API reference in the sidebar is generated from the `v4` branch as it
stands. Until the rewrite of `@ic-reactor/core` and `@ic-reactor/react` lands,
that is still their 3.x source.
