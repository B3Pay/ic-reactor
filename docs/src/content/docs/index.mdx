## Three libraries, one set of docs

Pick the library you work in. Each keeps its own packages and versions. Candid
Core's pages are on its own site until its repository moves into this one.

<LibraryCards />

## How they fit

1. **Your canister's interface:** a `.did` file, such as the ICRC-1 ledger's
   `icrc1.did`.
2. **Candid Core** turns it into a TypeScript module with
   `candid-core-cli gen`: the types, the schemas and the interface's identity.
3. **IC Reactor** gives that module a client: `client.queryOptions` and
   `client.mutationOptions` build the keys, calls and retries for whoever is
   signed in.
4. **Your app** hands them to TanStack Query's own `useQuery` and
   `useMutation`.

Start with [Getting started](/v4/guides/getting-started/), which takes an app
from nothing to a first read and a first write.

## Build something

Each build guide puts the pieces together into one small app, with a test:

- [Build an ICRC-1 wallet](/v4/build/icrc1-wallet/): a React page that signs
  in with Internet Identity, shows a balance and sends a transfer that is
  never paid twice.
- [Render a server page for one user](/v4/build/ssr-per-user/): a Next.js
  page for the account a URL names, read on the server and handed to the
  browser exact.
- [Give an agent a canister's tools](/v4/build/agent-tools/): an MCP server
  whose ledger tools put a transfer in words before sending it, and never pay
  twice.
