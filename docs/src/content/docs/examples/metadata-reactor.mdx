This example uses a `MetadataDisplayReactor` to connect to any canister by ID,
fetch its Candid at runtime, and show the form (input) and result (output)
metadata the reactor generates for each method. It is plain TypeScript, with no
framework.

## Features Demonstrated

- **Runtime Candid**: `initialize()` fetches the canister's interface, so no
  declarations are generated ahead of time.
- **Method Discovery**: `getMethodNames()` lists every method of the canister.
- **Input and Output Metadata**: `getInputMeta()` and `getOutputMeta()` return
  the field trees, defaults and schemas for the selected method.
- **Resolved Results**: `callMethod()` returns the result already resolved
  through the output metadata.

## Implementation

```typescript
// src/main.ts
import { ClientManager } from "@ic-reactor/core"
import { MetadataDisplayReactor } from "@ic-reactor/candid"
import { QueryClient } from "@tanstack/query-core"

const clientManager = new ClientManager({
  queryClient: new QueryClient(),
  agentOptions: { host: "https://ic0.app" },
})

const reactor = new MetadataDisplayReactor({
  canisterId, // entered by the user
  clientManager,
  name: "DynamicActor",
})

// Fetch the canister's Candid and build the metadata
await reactor.initialize()
const methods = reactor.getMethodNames()

// For the selected method
const argMeta = reactor.getInputMeta(methodName)
const resultMeta = reactor.getOutputMeta(methodName)

// The result comes back resolved through the output metadata
const result = await reactor.callMethod({ functionName: methodName as any })
```

See [MetadataDisplayReactor](/v3/packages/candid/metadatadisplayreactor) for the
metadata shapes.
